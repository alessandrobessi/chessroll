How it works

Stockfish analysis

Every position is analyzed by a real Stockfish process over UCI — never a hand-rolled heuristic. Raw scores are always relative to the side to move; a single normalization step flips them to White's perspective before anything else in the app sees them, and mate scores are never coerced into a fake centipawn number.

Deterministic rendering

Every frame is a pure function of its timestamp — renderAtTime(t) — with no wall clock, no CSS transitions, and no dependency on any previously rendered frame. The same input always produces the same video, byte for byte on the same machine.

CLI quick start

pnpm install
pnpm build
node dist/cli.js test/fixtures/puzzle.fen --template puzzle -o puzzle.mp4 --show-eval

See the README for every template, flag, and the full CLI reference.

Architecture

PGN / FEN → chess model → Stockfish analysis → story → scene timeline → renderAtTime(t) → Chromium frames → FFmpeg → MP4
